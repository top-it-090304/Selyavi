# Electric beam tile variants

Created 2026-11-11 using built-in image_gen for the curve variants. Four transparent 512 x 128 PNGs. Shared 64-pixel edge strips were restored from the same reference during asset packaging, with a 32-pixel transition. Left/right border pixel columns are equal. All shared RGBA edge pixels were compared programmatically. No gameplay code or beam renderer has been changed by this asset task.

01 is the reference curve. 02 bends upward, 03 downward, 04 has an S-shaped center.
